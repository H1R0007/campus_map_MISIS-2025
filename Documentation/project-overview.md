# 🗺️ Проект: Интерактивная карта кампуса

> Разработано Студенческим советом ИТКН  
> Цель: создать интерактивную 2D-карту вуза с возможностью перехода в "игровой режим"

---

## 🎯 Видение и цели

| Аспект | Описание |
|:------|:-------|
| **Основная цель** | Помочь студентам ориентироваться в кампусе и повысить узнаваемость Студенческого совета |
| **Первая версия** | Веб-приложение с интерактивной картой (передвижение, маршруты) |
| **Будущее развитие** | Добавление игровых элементов: квесты, достижения, мини-игры |
| **Два режима** | `Карта` (навигация) и `Игра` (развлечение + вовлечение) |
| **Платформа** | Сначала веб (через браузер) / мобильные приложения |

> 💡 Мы делаем не просто навигатор, а **платформу для взаимодействия студентов с СС**.

---

## 🛠️ Технический стек

| Компонент | Технология | Обоснование |
|:--------|:----------|:-----------|
| **Язык** | C++ | Есть опыт, высокая производительность, переиспользуемость |
| **Графика** | SFML | Простой 2D-рендер, поддержка Emscripten |
| **Компиляция в веб** | Emscripten | Преобразует C++ в WebAssembly (WASM) |
| **UI / Интерфейс** | HTML + CSS + JS | Лёгкая интеграция с WASM, гибкий дизайн |
| **Маршрутизация** | A* на графе помещений | Быстрый и точный поиск пути |
| **Хранение данных** | JSON | Человекочитаемо, легко редактировать без пересборки |
| **Сборка** | CMake + Emscripten | Кроссплатформенная сборка, поддержка WASM |

---

## 🔍 Сравнение технологий

| Критерий | SFML | SDL2 | Qt | Web Canvas (JS) |
|:--------|:----:|:----:|:---:|:---------------:|
| **2D-графика** | ✅ Отличная | ✅ Отличная | ✅ | 🟡 |
| **Поддержка WASM** | ✅ | ✅ | 🟡 (частично) | ✅ |
| **Сложность** | 🟢 Низкая | 🟡 Средняя | 🔴 Высокая | 🟢 |
| **C++ интеграция** | ✅ Прямая | ✅ Прямая | ✅ | 🔴 (через JS) |
| **UI-элементы** | ❌ | ❌ | ✅ (Qt Widgets) | ✅ (HTML) |
| **Для новичков** | ✅ Лучший выбор | 🟡 | 🔴 | ✅ |

> ✅ **Решение**: используем **SFML + HTML/CSS** — C++ для логики, веб для UI.

## 🔒 Инварианты проекта

> Эти принципы **не меняются без веской причины**.

| Принцип | Обоснование |
|:--------|:-----------|
| **C++ как основа** | Переиспользование кода, производительность, контроль |

| **Открытость архитектуры** | Поддержка будущего "игрового режима" |
| **Git для всего** | Полный контроль версий, история изменений |
