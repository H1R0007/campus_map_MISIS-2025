### 🔗 Связи между компонентами

| Связь | Описание |
|:-----|:--------|
| **Пользователь ↔ Веб-интерфейс** | Ввод: клики, колесо мыши, кнопки |
| **Веб ↔ WASM** | Вызовы C++ функций через `emscripten.h` |
| **WASM ↔ Renderer** | Отрисовка карты, спрайтов, UI-слоя |
| **WASM ↔ Navigation** | Управление камерой, телепортация |
| **WASM ↔ Data** | Загрузка JSON с картами, кабинетами |
| **Data ↔ Graph** | Построение графа проходимости для A* |
