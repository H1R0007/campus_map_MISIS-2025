# Видение проекта

Цель — создать **интерактивную 2D-карту корпусов вуза**, которая:
- Помогает студентам ориентироваться
- Становится лицом Студенческого совета ИТКН для привлечения новых ребят
- Может эволюционировать в **игру-навигатор** с квестами, достижениями, мини-играми(поздняяя задача)

Первая версия — **интерактивная карта в браузере**, с возможностью:
- Панорамирования и зума
- Перемещения по этажам
- Построения маршрутов(Дополнительная функция типа: точка-точка -> построен оптимальный маршрут)
- Общее перемещение

В будущем — **два режима**:
1. **Карта** — функциональная навигация
2. **Игра** — квесты ("найди офис СС" и т.п.)

> Мы делаем не просто приложение, а **платформу для привлечения студентов в СС**.

### Философия проекта

| Принцип | Объяснение |
|:-------|:----------|
| **Полезность прежде всего** | Сначала — навигация. Игра — опционально |
| **Открытость** | Код и данные открыты, чтобы другие могли участвовать |
| **Простота** | Интерфейс должен быть понятен с первого взгляда |
| **Развитие СС** | Проект — лицо Студенческого совета в цифровом пространстве |
| **Кроссплатформенность** | Работает в браузере, может стать мобильным приложением |
