# 🏗️ Архитектура проекта

Описание модульной структуры, связей между компонентами и принципов проектирования.

---

### 🧩 Архитектурная схема
[Пользователь]

↓ (ввод: клик, передвижение)

[Веб-интерфейс (HTML/JS)]

↓ (вызовы)

[WASM-модуль (C++)]

├──→ Renderer (SFML)

├──→ Navigation (pan, zoom)

├──→ Routing (A*)

└──→ Data Loader (JSON)

---

### 📦 Основные модули

| Модуль | Отвечает за | Технологии |
|:------|:------------|:----------|
| **Core (C++)** | Логика, рендер, математика | C++, SFML, GLM |
| **Renderer** | Отрисовка карты, спрайтов, UI-слоя | OpenGL (через SFML) |
| **Navigation** | передвижение, ?zoom? - нужен ли | События мыши, камера |
| **Routing** | Построение маршрута между точками | Граф, A*, JSON-описание |
| **Data Loader** | Чтение JSON-карт, этажей, кабинетов | nlohmann/json |
| **Web Bridge** | Обмен данными между JS и WASM | emscripten.h |

---

### 🔄 Принципы проектирования

| Принцип | Описание |
|:-------|:--------|
| **Модульность** | Каждый компонент — отдельный класс/файл |
| **Чёткие интерфейсы** | Минимум зависимостей между модулями |
| **Данные вне кода** | Карты и маршруты — в JSON, не в C++ |
| **На_будущее_** | Поддержка "игрового режима" через флаг `game_mode` |
