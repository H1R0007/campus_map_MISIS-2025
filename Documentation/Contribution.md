# 🤝 Contribution Guide

Как вносить вклад в проект

---

### 🚀 Как начать? (стоит обсудить стратегию разработки!)

1. **Форкни репозиторий**
2. Создай ветку: `git checkout -b feature/ваша-фича`
3. Внеси изменения
4. Сделай коммиты с понятными сообщениями
5. Запуши: `git push origin feature/ваша-фича` (в свой форк репозиторий)
6. Открой **Pull Request** в `main`

---

### 📝 Стандарты

#### ✅ Коммиты
- На английском языке
- Формат: `<тип>: <описание>`
  - `feat: add zoom functionality`
  - `fix: camera out of bounds`
  - `docs: update roadmap`
  - `refactor: split renderer class`

и т.п.

#### ✅ Код
- C++: соблюдай стиль (используй `.clang-format`, если есть)
- Комментируй сложные участки
- Не пиши "магические числа" — используй константы

#### ✅ Pull Request
- Укажи:
  - Что сделал
  - Почему
  - Как тестировать (опционально)
- Приложи скриншоты (если UI)

---

### 🧪 Тестирование
- Проверь, что сборка проходит
- Убедись, что не сломал существующую функциональность
- Запусти в браузере (через локальный сервер `python -m http.server`)
